# QhySync design brief

## Direction

**Neon companion cockpit** — a calm, dark, translucent workspace where a small luminous avatar provides presence without competing with the conversation.

- **Design movement:** soft sci-fi utility, glass surfaces, luminous edge accents.
- **Core principles:** conversation first; expressive but restrained motion; honest system states; durable memory is visible and editable.
- **Color philosophy:** deep ink/navy base, cyan for active/healthy states, violet for intelligence, pink as a rare expressive accent.
- **Layout paradigm:** two-column chat-with-avatar workspace that collapses to one column on narrow screens.
- **Signature elements:** layered cyan-violet avatar, thin status pills, rounded glass panels, animated signal bars.
- **Interaction philosophy:** optimistic, low-friction, keyboard-friendly; never imply MCP authorization before the upstream provider grants it.
- **Animation:** slow breathing idle state; avatar mood label changes to Thinking, Speaking, and Ready during message flow; reduced-motion-friendly CSS can be layered by the host.
- **Typography:** clean system sans with compact uppercase labels and generous body line-height.
- **Brand essence:** a reliable companion that helps ideas become clear.
- **Brand voice:** warm, direct, curious, and transparent about capability boundaries.
- **Wordmark/logo:** QhySync wordmark paired with a cyan-violet orb containing a dark inner ring.
- **Signature brand color:** #64E6FF.
